### DriftSense

[repo](https://github.com/Sachin0496/DriftSense) · SEM navigation error recovery · won the Applied Materials track at SEMICON India 2026

You have a reference image at 1 nm per pixel. You have a microscope frame at somewhere between 8 and 12 nm per pixel, so you don't know the scale by a factor of ten. It might be rotated up to 5 degrees. And sometimes the site simply isn't in the frame, in which case the correct answer is to say so and stop.

Getting the network to find things was the easy half. Finding them was 42.7% wrong with classical matching, which is roughly "flip a coin but with more steps." The final model puts 98% of held-out scenes within 5 px and rejects every absent site in 600 CAD pairs and 700 SEM scenes. The rejection behavior is the part I'd defend in a review. We also wrote the 14 page paper, because the rubric asked and because I wanted the failure analysis on record.

Scale invariance, a 1.02M parameter cross-correlation net, sub-pixel refinement, CPU only, under 1.2 seconds per pair.

### Colibri

[repo](https://github.com/Sachin0496/colibri_for_qwen3.6_35B_A3B) · 35B MoE model on a 16GB laptop

Qwen3.6-35B-A3B does not fit in 16GB. This is well established. I streamed the int4 experts off disk through a bounded cache and wrote fused Metal kernels for the SwiGLU path, and got about 7 tokens/sec on an M4 and an i7-13700HX. That's 5.5x faster than llama.cpp running the same thing on CPU.

I did not shrink the model or drop the experts to int2 to make the number look better, which apparently is the usual move. There is a CUDA backend in the repo too. It is implemented and I cannot benchmark it, because I own a Mac. I've noted that honestly in the README instead of quietly implying it works great.

### CrisisCrew

[repo](https://github.com/Sachin0496/crisiscrew) · Stage 2 finalist, The Great Agent Hackathon by Freshworks

Customers notice outages before your dashboards do. CrisisCrew reads support tickets as incident telemetry: when a burst of complaints describes the same failure in different words, it opens one incident, hunts the cause, and updates the customers who never wrote in.

Five agents, an MCP server, an audit log, and a policy gate that halts and asks a human when an action exceeds its authority. The gate is the point. An agent that can issue a refund unsupervised is not a feature.

Detection, the agents, the gate and the UI are real and running. The world they act on is seeded scenarios, and the external APIs are designed but not wired. The UI says which is which, so you can check rather than trust me.

### DocuMind

[repo](https://github.com/Sachin0496/production_rag) · RAG over whole GitHub repositories

Ingests a repo including issues, PRs, commits, releases and contributors, then answers developer questions with citations. Seven typed payloads in Qdrant for semantic search, relational facts in PostgreSQL for the structural questions, 384-dim local embeddings, cross-encoder reranking, five services in Docker.

My favorite part is the refusal path. When retrieval comes back empty it says it doesn't know, and I care about that more than any benchmark number, because a confident wrong answer about someone's codebase is worse than no answer.

### Finetune

[repo](https://github.com/Sachin0496/Finetune) · QLoRA distillation of a slide deck agent

Taught gemma-4-E4B-it three specific behaviors with 4-bit QLoRA on a free Kaggle T4: emit a schema-valid deck plan, emit animation HTML, and pick the next tool call. 300 train / 60 val examples, all validated in pure Python rather than by eyeballing outputs. Rank 16 adapters, 200 steps.

It is one notebook. You press Run All. There is no configuration step and I intend to keep it that way.

### AI Suggested Replies

[repo](https://github.com/Sachin0496/ai-suggested-replies) · a metric that tries to prove itself wrong

Generates a grounded support reply, then scores it on five weighted dimensions. The interesting part is the perturbation harness: I deliberately degraded replies and checked whether the metric noticed and ranked them the way a human would. It passed 5/5 orderings across 30 cases each.

Scored 85.8/100 over 40 responses. Runs on the standard library with no API key, because a demo that needs your credentials isn't a demo, it's homework.

**Terra Mine** · Caterpillar Tech Challenge finalist, top 80 of 7,500 teams

A mixed fleet of autonomous trucks that pack a dump without being told where to dump. Decentralized claims via CBBA, Next-Best-Dump planning, collision-aware routing, a deterministic 30 Hz loop, and a Raspberry Pi node bridging UDP to WebSocket so real and simulated trucks share the same pile state. Hit ≤3.5 m spacing and ≥90% packing density against a 7.38 m / 41% baseline. It is TypeScript, React and Three.js on the front and Python underneath, which is a stack that made sense at 3 AM.

**Gaja Alert** · Snapdragon Multiverse finalist

On-device early warning for human-elephant conflict. YOLO gates a quantized 4B Qwen3-VL verifier on the Snapdragon X Elite NPU, an audio classifier provides an independent evidence path, and alerts go out with Hindi and Tamil translation and TTS. Three models, one NPU, 24 hours. The fans on that laptop have not been the same since.

**Wafer-Map Defect Classification**

811K wafer maps across 9 defect patterns with class weighting, per-class evaluation, SPC excursion monitoring via X-bar/R and EWMA and Western Electric rules, Cpk, yield models and SHAP attribution. I genuinely enjoy a good control chart. This is a personality flaw and I've made peace with it.

**S.C.A.N**

Structural crack analysis. A PyTorch U-Net/VGG-style CNN produces pixel-level masks, then converts confidence into a 0-100 severity score across 6 risk bands with maintenance recommendations. Shipped with a Streamlit front end so a civil engineer could actually use it.

**Memory Hierarchy Profiling Lab**

C and C++ microbenchmarks using pointer chasing, stride sweeps and streaming access, correlated against Linux `perf` counters for LLC misses, dTLB misses and stalled cycles. Exists because I wanted to know why code was slow instead of guessing. Mostly confirmed my guesses were wrong.

**Flōatchat**

Conversational analytics over ARGO ocean float data. NetCDF ingestion, PostgreSQL for metadata, ChromaDB for semantic search, Docker Compose for the whole thing.
